= Gérer une liste de surveillance dans Digital Advisor
:hardbreaks:
:toclevels: 1
:allow-uri-read: 
:toclevels: 1
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Vous pouvez afficher le tableau de bord pour différentes listes de surveillance, modifier les détails d'une liste de surveillance existante et supprimer une liste de surveillance.

.Étapes
. Dans le volet de gauche, sélectionnez *Listes de surveillance*.
+
L'écran *gérer la liste de surveillance* s'affiche.

. Sélectionnez le nom de la liste de surveillance pour afficher les détails du tableau de bord de la liste de surveillance.
. Sélectionnez *Modifier* pour mettre à jour les détails de la liste de surveillance.
. Sélectionnez *Supprimer* pour supprimer la liste de surveillance.
