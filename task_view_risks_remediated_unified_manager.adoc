= Identifiez les risques liés aux actions dans Digital Advisor et atténuez-les à l'aide d'Unified Manager ou d'un playbook Ansible.
:hardbreaks:
:toclevels: 1
:allow-uri-read: 
:toclevels: 1
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Vous pouvez analyser votre système de stockage en visualisant les actions et les risques, et les réduire à l'aide de Active IQ Unified Manager ou du PlayBook Ansible.

video::XusFvXM7h-E[youtube,width=848,height=480]
.Étapes
. Sélectionnez *Afficher toutes les actions* sur le tableau de bord.
. Sélectionnez *Actions* pour afficher les risques associés aux actions, sélectionnez *Risques* pour afficher tous les risques, ou sélectionnez *Systèmes affectés* pour afficher les systèmes qui nécessitent une attention.
+
Si le risque peut être réduit à l'aide de Active IQ Unified Manager, le image:spanner.png["Clé"] L'icône est mise en surbrillance et si le risque peut être réduit à l'aide d'Ansible PlayBook, le image:update_ansible.png["Mettez à jour Ansible"] l'icône est mise en surbrillance.



[cols="50,50"]
|===
| Pour limiter les risques à l'aide de Unified Manager | Pour limiter les risques avec le PlayBook Ansible 


 a| 
. Sélectionnez l’icône image:spanner.png["Clé"].
. Sélectionnez *Corriger* pour lancer Active IQ Unified Manager.
. Sélectionnez *Installer* pour installer Active IQ Unified Manager 9.7 ou une version ultérieure afin d'utiliser l'option *Fix It*.
. Sélectionnez *Mise à niveau* pour passer à Active IQ Unified Manager 9.7 ou version ultérieure afin d'utiliser l'option *Fix It*.

 a| 
. Sélectionnez l’image:update_ansible.png["Mettez à jour Ansible"]icône.
. Sélectionnez *Télécharger* pour télécharger le package d'automatisation Ansible du firmware AFF et FAS.


|===

NOTE: Un contrat SupportEdge Advisor ou SupportEdge Expert est requis pour utiliser l'option *Fix it* et les fonctionnalités du manuel Ansible.
